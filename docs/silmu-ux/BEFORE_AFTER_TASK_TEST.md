## A. 수의계약 한도

| | BEFORE | AFTER |
|---|---|---|
| 쿼리 | `3000만원 물품 수의계약 가능한가요` | 동일 |
| 결과 | topics 6 · guides 5 | topics 1 · guides 5 |
| 1위 토픽 | `price-negotiation` (가격협상 — 오답) | `private-contract` (정답 주제) |
| 바로 답 | 없음 | 없음(FAQ 임계 미달 — 정직) |
| 답까지 클릭 | 3 (검색→목록 스캔→토픽 열기→본문에서 찾기) | 2 |

`수의계약 한도` 로 물으면: **바로 답 = "수의계약 한도 금액에 부가세가 포함되나요?"** 가 즉시 뜬다(클릭 0).
결과 수는 6→1 로 줄었지만 줄어든 5건은 pg_search 폴백 잡음이었다. **개수가 아니라 정답이 올라왔다.**

## D. 정보공개 처리기한 — **개선 없음 (정직한 측정)**

| | BEFORE | AFTER |
|---|---|---|
| 결과 | 0건 | **0건** |
| 원인 | 콘텐츠 부재 | 동일 |
| 화면 | "검색 결과가 없습니다" + 추천 키워드 | + 다른 표현 안내(업무 말→법령 용어) + **"이 업무를 요청하기"**(/feedback) |

`정보공개` 는 topics·guides·audit_cases·faqs **전 자산 0건**이다.
검색 엔진을 고쳐도 없는 콘텐츠는 나오지 않는다. **UX 로 덮지 않고 없다고 말한다.**
→ 홈 예시 질문에서도 정보공개를 뺐다(첫 클릭이 빈손이면 안 된다).
→ 이 검색어는 `SearchLog.zero_result` 로 남아 §42 Question Radar 의 signal 이 된다.
→ **P2 콘텐츠 확대 1순위 후보.**
