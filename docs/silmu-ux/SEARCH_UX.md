## 1. 문제 (실측)

`Topic.search_multiple` 이 전 토큰 AND 매칭이라 자연어 질문의 조사·어미·의문사가
recall 을 구조적으로 0 으로 만들었다. §17 의 예시 문구를 그대로 넣어 측정했다.

| 쿼리 | before | after |
|---|---:|---:|
| `병가 며칠 쓰면 진단서 내야 하나요` | **0** | **3** (sick-leave 1위) |
| `출장비 얼마 지급하나` | **0** | **9** (travel-expense 1위) |
| `처음 계약을 맡았어요` | **0** | **6** |
| `연가 돈으로` (토픽) | **0** | **1** (annual-leave) |
| `업체 하나 견적` | 1 | 12 |
| `수의계약 한도` | 12 | 12 |
| `정보공개 처리기한` | **0** | **0** ← 콘텐츠 부재. 정직한 0 |

`3000만원 물품 수의계약 가능한가요` 는 토픽 6→1 로 **줄었다**. 종전 6건은 pg_search 폴백이
낸 잡음(1위 `price-negotiation`)이었고, 지금 1건은 `private-contract` 다 — 개수는 줄고 정답이 올라왔다.

## 2. 엔진 변경 (파일 2개, 신규 클래스·테이블·마이그레이션 0)

### `app/services/search_query_parser.rb`
1. **STOPWORDS** — 조사·어미·의문사를 토큰에서 제거. 토큰 "전체"가 stopword 일 때만 제거하며
   부분 문자열은 건드리지 않는다.
2. **전량 stopword 가드** — 다 걸러지면 원본 토큰을 되살린다. "거를 게 없는 것"과
   "다 걸러진 것"은 다르다. 이게 없으면 `며칠 하나요` 가 빈 쿼리가 된다.
3. **조사 분리(PARTICLES)** — `계약을` → `계약` 을 **추가 변형**으로 넣는다(대체 아님, 순수 가산).
   어간 최소 2자(`자가`→`자` 같은 오분리 차단). **처음 일치한 조사에서 판정을 끝낸다** —
   계속 짧은 조사를 시도하면 `돈으로` 가 `돈으` 라는 쓰레기 어간을 만든다(실제로 만들었고, 고쳤다).
4. **문장부호 정규화** — `가능한가요?` 가 stopword 로 인식되도록 꼬리 부호를 뗀다.
5. **동의어 7쌍 추가** — 연가/연차/진단서/차비/견적/1인견적/공개청구. 대량 생성 안 함(§54).

### `app/models/topic.rb`
6. **점진적 완화 `relaxed_match`** — 전 토큰 AND 가 0건일 때**만** 발동.
   토큰 과반 이상 매칭을 채택하고 **매칭 토큰 수 DESC** 로 정렬한 뒤 기존 랭킹을 잇는다.
   정확 매칭이 이미 0건이므로 순위 역전은 구조적으로 발생하지 않는다.
   단일 토큰이면 완화가 AND 와 같아지므로 발동하지 않고 기존 pg_search 폴백을 유지한다.
   ORDER BY 는 바인드를 못 받으므로 sanitize 된 리터럴 절을 병행 생성한다(주입 안전성 유지).

**탐색 순서**: `전 토큰 AND` → `과반 완화` → `pg_search 폴백` (§55: authority/freshness 를 relevance 에 섞지 않음)

## 3. Answer-First (§20·§21)

### 데이터 출처 — 새로 만들지 않았다
`topics.faqs` 에 **검증된 FAQ 331건(74 토픽)** 이 이미 있었다. `{question, answer}` 구조.
P1.6 은 이걸 **드러낼 뿐** 생성·요약하지 않는다.

### `Topic.answer_for(query, topics)`
검색 결과 토픽들의 `faq_list` 중 **질문에 검색어 내용 토큰이 과반 이상** 들어간 FAQ 를 고른다.
과반 미달이면 `nil` → **카드를 아예 그리지 않는다.** 약한 매칭에 "바로 답" 딱지를 붙이면
그게 거짓 신뢰다(§32 의 정신을 답 카드에도 적용).

### 결과 화면 순서
```
① 바로 답 (있을 때만)  ② 실무 도구  ③ 법령 가이드  ④ 감사사례  ⑤ 실무 가이드  ⑥ 서식
```
바로 답 카드에는 `shared/_verification_badge`(compact)로 검증 상태를,
`AuthorityPresenter#show_agency_scope?` 가 HIGH 일 때만 적용 대상을 붙인다.
**모델 직접 접근 없음** — 구현 중 `topic.agency_labels`(모델엔 없는 메서드)를 부르는
경계 위반을 한 번 저질렀고, 그 분기를 실제로 렌더하는 테스트를 추가해 고정했다.

## 4. Zero Result (§41·§42)

```
before:  "검색 결과가 없습니다" + 추천 키워드 칩
after :  + 다른 표현 안내(업무 말 → 법령 용어 3쌍 예시)
         + 둘러보기 2개 + "이 업무를 요청하기"(/feedback)
```
`SearchLog.zero_result` 기록은 **이미 있던 것을 그대로 쓴다**(§42 Question Radar 의 signal 기반).
새 Radar 본체는 만들지 않았다.
