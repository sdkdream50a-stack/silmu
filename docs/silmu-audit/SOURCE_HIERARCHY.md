# SOURCE_HIERARCHY — 출처 신뢰도 등급 체계

> 사이트 전체가 **같은 등급 어휘**를 쓰지 않으면 "근거가 확실하다"는 주장은 성립하지 않는다.
> 현재 실측: 토픽은 Tier 1 딥링크 813개를 보유하는 반면, **감사사례 257건은 원문 링크 0건**이면서 96%가 검증 배지를 단다(TR-01).

---

## 1. 등급 정의

### Tier 1 — 1차 공식 원문 (정답의 근거가 될 수 있음)
| 기관 | 도메인 | 현재 사이트 인용 |
|---|---|---:|
| 법제처 국가법령정보센터 | `law.go.kr` | **656** |
| 행정안전부 | `mois.go.kr` | 115 |
| 조달청 나라장터 | `g2b.go.kr`, `pps.go.kr` | 113 |
| 기획재정부 | `moef.go.kr` | 1 |
| 감사원 | `bai.go.kr` | **0** |
| 인사혁신처 | `mpm.go.kr` | **0** |
| 교육부 | `moe.go.kr` | **0** |
| 법원 / 헌법재판소 | `scourt.go.kr`, `ccourt.go.kr` | **0** |
| 국민권익위원회 | `acrc.go.kr` | **0** |
| 자치법규정보시스템 | `elis.go.kr` | **0** |

> 🔴 **감사원·인사혁신처·교육부·법원 인용이 0건이다.** 감사사례 257건과 보수·수당 45건이 각각 감사원·인사혁신처를 근거로 삼아야 하는데, 실제 링크는 없다.

### Tier 2 — 기관 공식 자료 (근거 가능, 적용 범위 명시 필수)
시·도 / 교육청 / 공공기관 공식 발간물, 지방재정365(`lofin.mois.go.kr`), 지방교육재정알리미, ALIO(`alio.go.kr`), 각 기관 자치법규·훈령.
→ **반드시 `applicable_region` / `education_office`를 함께 기록한다.** 이것이 오류 유형 D(지역 혼재)의 방지 장치다.

### Tier 3 — 전문기관 해설·실무서
공신력 있는 해설서, 전문기관 교육자료. **보조 설명에만 사용. 결론의 단독 근거로 쓰지 않는다.**

### Tier 4 — 커뮤니티 (근거 아님)
공개 카페, 현직자 블로그, 커뮤니티 게시물.
현재 `cafe_articles` 테이블에 **50,000행**이 수집되어 있다.

> **Tier 4의 유일한 정당한 용도: 질문·실무 애로사항의 발견.**
> 정답의 근거로 사용 금지. `authority_status = COMMUNITY_DERIVED`는 "이 질문이 어디서 왔는가"를 뜻하지 "이 답이 맞다"를 뜻하지 않는다.
> → `QUESTION_RADAR_DESIGN.md`가 이 50,000행의 올바른 소비처다.

## 2. 사용 규칙 (기계 검사 가능)

| 규칙 | 내용 | 검사 |
|---|---|---|
| SH-1 | 금액·기한·비율·자격요건 결론은 **Tier 1 근거 필수** | 본문 수치 블록에 Tier 1 URL 존재 |
| SH-2 | Tier 2 근거는 적용 지역/기관을 함께 표기 | `applicable_region` non-null |
| SH-3 | Tier 3은 단독 근거 금지 (Tier 1·2와 병기) | Tier3만 있는 결론 0건 |
| SH-4 | Tier 4는 `EVIDENCE` 그래프에 연결 금지 | `QUESTION` 노드에만 연결 |
| SH-5 | 원문 URL이 없으면 검증 배지 렌더 금지 | `official_source_url` 존재 |
| SH-6 | 등급은 **콘텐츠가 아니라 개별 근거(claim)** 단위로 부여 | — |

## 3. 표기 형식 (사용자 화면)

```
근거
  [Tier 1] 지방자치단체를 당사자로 하는 계약에 관한 법률 시행령 제25조 제1항 제5호 나목
           시행 2026-05-20 · 법제처 국가법령정보센터 원문 →
  [Tier 1] 지방자치단체 입찰 및 계약집행기준 (행정안전부 예규 제OOO호)
           시행 2026-01-02 · 행정안전부 원문 →
  [Tier 2] ○○교육청 계약업무 처리지침 — ○○교육청 소속에만 적용
```

Tier 3·4는 근거 블록에 넣지 않는다. Tier 4는 별도 "실무에서 자주 나오는 질문" 블록으로 분리한다.
