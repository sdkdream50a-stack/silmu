## 4. P1.6 이 실제로 무엇을 고쳤는지 (부수 실측)

과거 zero_result 로 기록된 120개 질의를 **오늘 다시 돌렸다.**

```
지금 콘텐츠가 나오는 것   24 / 120  (20.0%)
여전히 0건               96 / 120  (80.0%)
그중 바로 답까지 뜨는 것    2 / 120
```

로그의 zero_result 는 **P1.6 recall 복구 이전** 기록이 섞여 있다.
따라서 **과거 zero_result 를 그대로 현재 NO_CONTENT 로 쓰면 20% 를 과대계상한다.**
이 문서의 100건은 과거 기록이 아니라 **오늘 재측정한 값**이다.

## 6. 읽을 때 주의

1. **"중고 책 사는데 유의사항이 따로 있어?" 55회** — 단일 문장이 55회 반복됐다.
   자연 트래픽이 아니라 시연·봇일 가능성이 높다. **우선순위에서 빈도 가중치를 그대로 주지 않는다**(04 §3).
2. `origin=ZERO` 인데 오늘 T>0 인 행은 **P1.6 이 이미 부분 해소**한 것이다. NO_CONTENT 로 세지 않았다.
3. `top_slug` 가 질문과 무관해 보이는 행(예: "책 제본" → `disciplinary-action`)은
   **완화 매칭(relaxed_match)의 부산물**이다. 검색 결과에는 뜨지만 답은 아니다 —
   그래서 `answer_for` 가 정직하게 nil 을 준다. 이건 결함이 아니라 P1.6 정밀도 정책이 작동한 결과다.
4. 한 질의가 여러 GAP_TYPE 을 동시에 가질 수 있다. 분류는 **위에서부터 먼저 참인 것 하나**다
   (NO_CONTENT → WEAK → NO_DIRECT_ANSWER → NO_ACTION_STEPS → NO_EVIDENCE → NO_TOOL → COVERED).
