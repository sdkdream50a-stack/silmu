# 08 — NEWCOMER MODE

> §22. "처음 맡은 업무"가 별도 product surface 가 될 가치가 있는지 **실측 기반으로** 판정한다.

---

## 1. 지금 있는 것 (실측)

| 자산 | 상태 |
|---|---|
| `/start` (`guides#onboarding`) | ✅ **존재·운영 중**. `ONBOARDING_TRACK` 7단계 하드코딩 · 운영 화면에서 **7/7 렌더 실측** |
| 7단계 구성 | ① 오리엔테이션(적용 법) ② 계약방식 정하기 ③ 수의계약 실무 ④ 예정가격 작성 ⑤ 나라장터 전자계약·입찰 ⑥ 검사·검수와 대가지급 ⑦ 사고 안 나게: 쪼개기 금지와 첫달 마무리 |

> **Newcomer Mode 는 이미 존재한다. 다만 계약 전용이다.**

## 2. 실측된 문제 — 범위가 계약 하나뿐이다

| 축 | 실측 |
|---|---|
| `/start` 가 다루는 업무 | **계약·조달 1종** |
| §22 가 예시로 든 6종 | 처음 계약 ✅ / 처음 예산편성 ❌ / 처음 정보공개 ❌ / 처음 감사 대응 ❌ / 처음 물품관리 ❌ / 처음 출장 정산 ❌ |
| "처음 계약 맡은 신규자" 질의 재측정 | **Topic 0 · Guide 1 · AuditCase 0 · 바로 답 없음** → `WEAK_CONTENT` |
| 홈 카드 hint | "계약·예산·지출·급여를 처음 맡았다면" — **예산·지출·급여 트랙은 실제로 없다** |

### 2.1 카드 문구와 실제 내용이 어긋난다

`TaskEntryHelper` 의 `newcomer` 카드 hint 는 **"계약·예산·지출·급여"** 4종을 약속하는데
`/start` 는 계약 7단계만 준다. count 80 은 `guide_series: :any_series` 로 **모든 시리즈 80편**을 세서
나온 숫자지 온보딩 트랙의 크기가 아니다.

이건 결함이라기보다 **약속 > 실물**인 상태다. P2 가 정직하게 정할 것은 둘 중 하나다:
① 트랙을 늘려 약속을 맞춘다 ② hint 를 실제 범위로 줄인다.

### 2.2 검색에서 신규자 질의가 잡히지 않는다

"처음 계약 맡은 신규자" 로 검색하면 **`/start` 가 결과에 나오지 않는다** —
온보딩은 Topic/Guide/AuditCase 어디에도 레코드가 없는 **컨트롤러 상수**라 검색 인덱스에 없다.
`ONBOARDING_TRACK` 은 DB 밖에 있다.

> 그래서 신규자는 홈 카드를 **눈으로 발견**해야만 도달한다. 검색으로는 못 온다.

## 4. 별도 product surface 가 될 가치가 있는가 — 판정

```
STATUS: EXISTS_BUT_SINGLE_TRACK
VERDICT: 별도 surface 로 **승격할 가치 있음**. 단 조건부.
```

**찬성 근거(실측)**
- 재료 보유 트랙 5종 (예산편성·예산집행·출장정산·급여복무·감사대응) — 신규 저작 0
- 홈 카드가 이미 4종을 약속하고 있다(문구 존재)
- `filter_map` 구조 덕분에 **미발행 항목은 자동 제외**된다 — 빈 트랙이 뜨지 않는다
- 신규자 난도(D축)가 상위 20 중 13건에서 3점 — 신규자는 **모든 업무의 공통 축**이다

**반대·주의 근거(실측)**
- "처음 계약 맡은 신규자" 실제 관측 질의 = **seed 뿐, 자연 로그 0건**
  → 신규자가 그런 문장으로 검색하지 않는다. **입구는 검색이 아니라 내비게이션**이다
- `/start` 가 검색 인덱스 밖이라 지금은 **도달 경로가 홈 카드 1개뿐**
- 트랙을 늘리면 `ONBOARDING_TRACK` 상수가 커진다 — DB 이전 여부는 별도 판단

## 7. 다음 세션이 먼저 확인할 것

1. ~~`/start` 가 7단계 전부 렌더되는가~~ → **이 세션에서 실측 완료.**
   운영 `https://silmu.kr/start` 응답에서 단계 제목 **7/7 전부 렌더**된다:
   오리엔테이션 → 계약방식 정하기 → 수의계약 실무 → 예정가격 작성 →
   나라장터 전자계약·입찰 집행 → 검사·검수와 대가지급 → 사고 안 나게: 쪼개기 금지와 첫달 마무리.
   `red_flags`(“이렇게 하면 걸려요”) 는 5/7 단계에 붙어 있다(1·2단계는 원래 빈 배열).
   → **`filter_map` 이 조용히 떨어뜨린 항목은 없다.**
2. `/start` 유입량 — 현재 계측 없음(11 문서 이벤트 후보)
