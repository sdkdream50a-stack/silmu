## 5. 잡 로그

```json
[AuthorityFreshness] {"checked":8,"unchanged":8,"changed":0,"failed":0,"tasks_created":0,"skipped_failing":0}
```
구조화 JSON — 로그 수집기에서 바로 집계 가능. lograge 가 설정되어 있다.

## 6. 실패 가시성

세 종류로 구분되어 `authority_sources` 에 남는다.
```
FETCH_FAILED        네트워크·HTTP
PARSE_FAILED        응답은 왔으나 해석 실패 (검색 결과 0건 포함)
SOURCE_UNAVAILABLE  예외·서비스 장애
```
어느 것도 "법령 삭제"로 해석되지 않는다. 실패 시 version 은 생성되지 않고 문서 `status` 는 `ACTIVE` 를 유지한다.
