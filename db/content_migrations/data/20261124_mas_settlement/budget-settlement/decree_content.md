## 결산 일정 — 출납 폐쇄부터 의회 승인까지

**지방자치단체(일반회계·특별회계·기금) 기준.** 교육비특별회계는 아래 「교육비특별회계와 학교회계」를 함께 보세요.

<div style="background:#dcfce7;padding:12px;border-radius:8px;margin:8px 0;">
| 시기 | 할 일 | 근거 |
|------|------|------|
| **12월 31일** | 회계연도 종료 = **출납 폐쇄** | 지방회계법 제7조① 본문 |
| ~ 다음 연도 **1월 20일** | 예외적 수입·지출 처리. 해당 연도 예산에 있고 연말 계약 이행 완료·자금 미교부·시행령 제3조 사유(보조금 정산 반납, 신용카드 대금 등)일 때만 | 같은 조 ① 단서, 시행령 제3조 |
| ~ 1월 20일 | 출납원 세입금 금고 납입, 일상경비 반납 | 같은 조 ② |
| ~ **2월 10일** | **출납사무 완결** | 같은 조 ③ |
| 출납 폐쇄 후 **80일** 이내 (3월 20~21일경) | 결산서·증명서류 **작성** | 지방자치법 제150조① |
| 작성 후 | 의회가 선임한 검사위원 검사 → 검사 끝난 뒤 10일 이내 검사의견서 제출 | 지방회계법 제14조①, 지방자치법 시행령 제84조③ |
| ~ **5월 31일** | 결산서 + 검사의견서를 지방의회에 **제출** | 지방회계법 시행령 제10조① |
| 승인 요청일부터 5일 이내 | 결산서를 행정안전부장관에게 제출 | 지방회계법 제14조⑤ |
| 제출받은 날부터 7일 이내 | 의회 의장이 검사의견서·검사위원 성명을 의회 홈페이지에 공개(10년 이상) | 지방회계법 시행령 제10조② |
| **다음 해** 의회 | 지방의회 결산 **승인** (법에 정한 날짜는 없음) | 지방자치법 제150조① |
| 승인 후 5일 이내 | 시·도는 행정안전부장관, 시·군·구는 시·도지사에게 보고하고 고시 | 지방자치법 제150조② |

※ **80일은 작성 기한**입니다. 의회 제출 기한은 5월 31일, 승인은 "다음 해"로만 정해져 있습니다.
</div>

**결산서 구성 (지방회계법 제15조)**

<div style="background:#eff6ff;padding:12px;border-radius:8px;margin:8px 0;">
1. 결산 개요 — 제2호~제4호를 주민이 이해하기 쉽게 요약(제16조①)
2. 세입·세출 결산 — 예산·기금운용계획과 같은 구분으로 집행 결과 작성(제16조②)
3. 재무제표(주석 포함) — 재정상태표, 재정운영표, 순자산 변동표. 공인회계사 검토의견 첨부(제16조③)
4. 성과보고서 — 성과계획서의 목표와 실적 대비(제16조④)

함께 작성하는 증명서류(지방자치법 제150조①)와 부속서류의 세부 양식은 시행령과 행정안전부(교육비특별회계는 교육부) 결산 기준을 따릅니다.
</div>
